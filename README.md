# FinRiskAI — AI-Powered Financial Risk Prediction

End-to-end portfolio project for predicting corporate financial risk from financial statements.

## Features
- CSV financial-statement ingestion
- Feature engineering: liquidity, leverage, profitability, efficiency and cash-flow ratios
- Explainable ML risk classifier
- Default / distress probability
- Risk bands: Low / Medium / High
- SHAP-style feature importance via model coefficients / permutation importance
- FastAPI REST API
- React + Vite dashboard
- PostgreSQL persistence
- Docker Compose
- Training pipeline
- Model artifact persistence
- Health and model-info endpoints

## Model
The default demo uses a synthetic dataset generated by `scripts/generate_data.py`, then trains a calibrated Random Forest classifier. Replace the synthetic data with a real, properly licensed dataset for serious evaluation.

## Quick start

### 1. Start services
```bash
docker compose up --build
```

### 2. Generate demo data and train
```bash
docker compose exec backend python scripts/generate_data.py
docker compose exec backend python scripts/train.py
```

### 3. Open
- Frontend: http://localhost:5173
- API docs: http://localhost:8000/docs
- API health: http://localhost:8000/health

### 4. Predict
Upload a CSV through the dashboard or POST JSON to `/api/v1/predict`.

Example:
```json
{
  "company": "Demo Corp",
  "current_assets": 250,
  "current_liabilities": 180,
  "cash": 60,
  "total_assets": 900,
  "total_liabilities": 520,
  "equity": 380,
  "revenue": 1000,
  "ebit": 120,
  "net_income": 75,
  "operating_cash_flow": 105,
  "interest_expense": 25,
  "inventory": 140,
  "accounts_receivable": 110,
  "debt": 300
}
```

## Important
This is an educational/portfolio risk model, not investment advice or a regulated credit decisioning system. A real deployment needs validated labels, representative historical data, calibration, drift monitoring, fairness testing, governance, audit logs, and domain/legal review.
